## Instalación local

```bash
# Clonar el repositorio
git clone https://github.com/SantiMarin07/portafolio-react.git

# Entrar al directorio
cd portafolio-react

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

> Para actualizar el contenido del portafolio, solo edita el archivo `src/data/portafolioData.js`. No necesitas tocar los componentes.
