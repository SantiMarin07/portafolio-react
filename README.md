## Qué hay en este repo

```
src/               Sitio del portafolio en React + Vite
src/data/          portfolioData.js: todos los textos, servicios y proyectos del sitio
public/vitrinas/   Página de vitrinas 3D (Three.js), con sus fotos, videos y el modelo de la Gixxer
kit-blender/       Escenas de producto hechas por código en Blender para Reels, TikTok y anuncios
```

Para cambiar el contenido del sitio solo hay que editar `src/data/portfolioData.js`; los componentes no se tocan.

## Correr en local

```bash
git clone https://github.com/SantiMarin07/portafolio-react.git
cd portafolio-react
npm install
npm run dev      # http://localhost:5173
npm run build    # genera dist/
```

Cada push a `main` se publica solo en Vercel.
